Detailed Description

Representa a entidade Livro no sistema de gestão. Armazena as informações de catálogo, preço, estoque e controla o histórico de exemplares alugados.

◆ devolver()

boolean gestaolivros.Livro.devolver ( )

Processa a devolução do exemplar alugado há mais tempo. O algoritmo varre a fila de empréstimos buscando a data de devolução mais antiga (isBefore) e remove este registro da fila, reajustando os índices do array e incrementando o estoque.

  • Returns
    true se a devolução for processada, false se não houver exemplares emprestados.
